# 1.83 动态节流参数持久化

动态节流设置复用已有 `/api/preferences` 接口，写入 `/config/state/ui-preferences.json`，不再只保存在当前浏览器。

保存项：启用开关、节流模式、进入闲置延迟、闲置帧率上限、节流强度，以及由模式 / 强度计算的 H.264 CRF、采样比例和禁用精绘标志，共 8 项。派生值仍按原模式逻辑计算，不新增互相冲突的独立控件。

打开页面时优先恢复服务端配置；服务端尚无该项时导入当前浏览器缓存。修改通过现有合并写入、失败重试及离线缓存路径保存。换浏览器可读取同一容器的共享设置；重建容器需保留 `/config` 卷。

旧版强制把节流强度迁移为 10 的逻辑不再覆盖用户已有值。新用户仍使用默认值，鼠标停留 / 离开、触屏、音频活动和深度休眠规则保持 1.82 行为。

验证：偏好存储重载、非法参数拒绝且不部分覆盖、现有客户端离线重试检查通过。真实 Chromium 修改全部面板参数后，确认 8 项写入服务端；移除并重建隔离测试容器，挂载同一配置卷，使用全新浏览器会话确认参数全部恢复。

部署：导入 `wechat-selkies-1.83-intel.tar`，将项目镜像改为 `wechat-selkies:1.83`，保留原配置卷 / PIN / 端口 / GPU 映射并重建、刷新页面。休眠仍建议显式设置 `SELKIES_CONTAINER_SLEEP=true`，防止 NAS 继承更早版本的 `false`。
