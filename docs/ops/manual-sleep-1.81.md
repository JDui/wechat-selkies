# 1.81 手动休眠

侧边栏“妙妙小工具”的待机时间下方新增“进入休眠”。按钮调用现有鉴权后的休眠接口，确认成功后退出当前网页会话并回到 PIN 登录页；输入正确 PIN 恢复工作进程。不增加确认弹窗，按钮旁说明休眠期间微信 / QQ 暂停运行。

手动休眠独立于“自适应休眠”自动计时开关。后台关闭自动计时不再撤销手动休眠；整个容器休眠功能被禁用时仍按原规则恢复工作进程。未启用休眠功能或未设置所需 PIN 时显示错误，不假装已休眠。请求失败后先查询状态，避免服务已休眠而响应丢失时误报。

继承 [1.80 静息资源优化](idle-resources-1.80.md)，深度休眠保留进程内存，暂停实时消息接收。普通静息仍运行微信 / QQ。

## 验证

- 9 项待机 / 偏好检查通过，包含关闭自动计时后手动休眠不会被监控循环唤醒。
- JavaScript 语法检查、镜像内 Python 编译检查通过。
- 本地隔离容器：真实 Chromium 点击侧边栏按钮后返回 PIN 登录页，自动计时关闭时仍持续休眠，健康检查通过。
- 实际暂停 29 个工作进程，错误 PIN 保持休眠，正确 PIN 恢复全部进程，恢复后健康检查通过。测试应用自动启动关闭，无真实账号数据。
- 本次未验证 NAS Intel GPU 使用率。截图属于可见页面静息，不等于深度休眠；缺少 GPU 引擎 / 进程时间序列，不能据此认定尖峰来自编码器故障。源码确认空闲帧率切换会重建 H.264 采集，但未证实无操作下反复切换。

## 部署

导入 `wechat-selkies-1.81-intel.tar` 后，把现有项目镜像改为 `wechat-selkies:1.81` 并重建，保留现有配置卷、PIN、端口和设备映射。刷新页面加载 1.81。仅导入镜像不会更新正在运行的容器。
