# 1.80 静息资源优化

## 范围与行为

- 微信和 QQ 继续分别运行自己的进程与线程，不拆成两个重复的桌面容器，不修改客户端网络、同步、通知或登录数据。
- 普通静息保持微信 / QQ 收消息；PIN 待机按用户选择计时，到时进入 `full` 深度休眠，冻结桌面、应用、推流、通知、上传等工作进程，仅保留 nginx 登录页、鉴权、唤醒及必要监督服务。PIN 唤醒恢复被冻结的进程。深度休眠不实时收消息，进程内存保留，不承诺内存接近零。
- 深度休眠期间健康检查改查登录 / 鉴权 / 唤醒服务，避免把主动暂停的上传服务判为故障。
- 修复休眠鉴权返回 418 导致 nginx `auth_request` 转成 500 的问题；改用 401 进入已有登录页映射。错误 PIN 不唤醒，正确 PIN 恢复工作进程。
- 所有浏览器页面隐藏后默认 60 秒停止音视频采集；可见页面即使失去键盘焦点也不触发这个策略。隐藏期间停止的是浏览器远程音频，桌面 PulseAudio 和通知服务保留。可用 `SELKIES_HIDDEN_STREAM_IDLE_SECONDS=0` 回到原自适应待机计时策略。
- 可见页面的空闲默认帧率为 2 FPS，键鼠操作沿用现有恢复路径。既有浏览器保存的帧率优先，不静默覆盖用户设置。
- 关闭采集时回收视频发送任务及缓冲，并对 Selkies 自身调用垃圾回收 / glibc `malloc_trim`；不清宿主机页缓存，不强行压缩微信或 QQ 工作集。
- 通知服务用已有 python-xlib 读取 EWMH 窗口、焦点、标题和紧急提醒，300 ms 快照复用，检测周期不变。X11 不可用或窗口管理器不支持时沿用旧命令查询。X11 重启后重新连接。
- 拖拽下载没有有效页面租约时不再高频查询。页面打开但没有拖拽时，通过已有 XFixes selection 事件等待拖拽开始，普通刷新降到 500 ms；事件到达立即唤醒，实际拖拽 / selection 传输保持 20 ms 时序。不支持 XFixes 时沿用旧轮询。浏览器无传输时的租约刷新从 750 ms 降到 1500 ms，拖拽和传输中的刷新频率不变。

## 日志

诊断归档 `.YYYYMMDD` 继续按日期清理；`.1/.2/...` 按原始修改时间和保留数量清理（默认 7 天、3 个）。维护在启动与每小时检查中执行，并与追加写入共享锁。没有事件、只有被过滤的 heartbeat 时也可以清理。其他后缀、目录和符号链接不在清理范围。

NAS 旧 `upload-diagnostics.jsonl.1`（134,266,654 字节，2026-09-11 最后写入）已按用户要求单独删除；当前活动日志及聊天数据保留。

## 构建与部署

可复用本机现成 `wechat-selkies:1.78`：

```sh
docker build -f scripts/ops/Dockerfile.idle -t wechat-selkies:1.80 .
```

该增量构建保留已验证可初始化的 Intel 媒体驱动，只更新本次运行脚本和页面默认值。完整 Dockerfile / Compose 同步到 1.80。升级镜像会重建容器，宜选择没有进行通话或文件传输的时段；持久配置映射保持原样。

本地检查与 NAS 上的实际消息收发、CPU / 内存下降是不同验收项，不以单元测试或构建成功替代真机验收。

## 本轮验证（2026-11-15）

- 日志轮转、待机设置、推流状态机定向检查通过；真实 Xvfb 检查确认焦点、微信标题 / 紧急提醒、QQ 窗口都可通过新查询路径取得，无查询子进程。
- 隔离容器同一对窗口做 5 轮对比：旧路径 120 个命令子进程、1.9148 秒墙钟 / 1.0352 秒进程与子进程 CPU；新路径 0 个子进程、0.0147 秒墙钟 / 0.0102 秒 CPU。这是窗口查询成本，不是整机 CPU 降幅。
- 普通静息的真实 CPU H.264 隐藏暂停 / 可见恢复路径已通过。1.80 隔离容器深度休眠实测暂停 29 个工作进程，登录页可达、健康检查通过；错误 PIN 不唤醒，正确 PIN 恢复全部 29 个进程并通过健康检查。约 3 秒等待采样（含探针开销）约占单核 1.85%，不是 NAS 真机测量。
- 真实 Xvfb 中，有页面租约而无拖拽时 650 ms 仅发生 1 次鼠标查询；模拟原生 selection 所有权变更后约 0.99 ms 激活拖拽接收区，确认没有等待 500 ms 轮询周期。
- 原有 Thunar 完整文件拖拽检查无法运行：1.78 基础镜像没有安装 Thunar。未为此额外安装软件；本轮验证原生拖拽事件和激活时序，真实微信 / QQ 完整拖拽及消息接收仍需 NAS 上验收。
- Windows 本机没有可映射的 Intel GPU；本轮不宣称验证 N355 硬编。1.78 的驱动包保持原样。
