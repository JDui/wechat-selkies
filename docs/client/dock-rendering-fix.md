# 状态胶囊绘制与动效修复

2026-10-26

- 26×26 收纳按钮与展开按钮共用固定左边距，8×8 状态点圆心始终位于 (13,13)，避免两种布局交接时的半像素偏移。
- 动画改变按钮实际宽度，由圆角边框正常绘制外形；移除对大按钮裁切、缩放的做法，避免边框缺失和边缘裁断。切网按钮通过 flex 布局跟随。
- 单独保存动画目标状态，尺寸 IPC 的 eval 推送和返回值不会重新启动收纳动画；反向操作从当前宽度继续。先等待原生视口预留，再展开；结束后收回多余宽度。
- 每个磨砂表面使用自身实际坐标采样背景，切网按钮移动时持续更新；呼吸提示只改变描边与阴影，文字保持稳定。
- 原生子视图增加 6px 绘制留白，保留圆角抗锯齿与柔和阴影，按钮在主窗口中的位置不变。

## 本轮验证

- `scripts/verify-dock-headless.mjs`：无界面 Chromium，模拟有延迟且双路回报的 IPC，检查 100% / 125% / 150% DPI 的圆心、动画中间宽度、展开/收纳完成、动画反向、过程中切换连接状态、背景坐标、面板开合及减少动态效果。全部通过。
- 现有 `ui_layout::tests::floating_controls_remain_inside_small_and_large_windows`：通过。
- `cargo build --release --locked --offline -j 1`：通过，编译进程使用低于正常的优先级。解压构建缓存中的 JS/CSS，与当前源码直接比较一致，且对应压缩内容确实嵌入便携 EXE；没有进行哈希校验。
- 新版位于 `axiver-client/dist/AXIVER-Client.exe`，同目录保留旧版备份。正在运行的 `D:/Program Files/AXIVER-Client/AXIVER-Client.exe` 未替换或重启，现有运行实例尚未应用修复。
- [结果数据](../../screenshots/dock-headless/results.json)。同目录 PNG 是用于辨认背景坐标的彩色条纹测试样例，不代表实际远端内容。

本轮没有启动、重启或聚焦原生客户端，没有操作游戏窗口。以上是源码、布局单测和无界面渲染验证，真实 WebView2 界面及游戏中的交互尚未验收。
